## Contracts

- B-10 Paths: string; not empty; no leading/trailing/consecutive dot; none of the 26 whitespace chars (`LOCATOR_SCHEMA_PATH_WHITESPACE`); runtime `validateLocatorSchemaPath` and type `LocatorSchemaPathFormat` agree, same order, every broken rule named; checked at `add`, `getLocator`, `getLocatorSchema`/`getNestedLocator`, `register`/`replace`. `utils.ts:19-108`, `types.ts:27-51`. Docs: locator-paths#the-rules-of-a-path, errors#paths, src/locators/AGENTS.md.
- B-11 Typed paths: union membership, template members, wide `string` (`<string>` "gives up every compile-time check"), variables, `NeedsPaths`. Docs: locator-paths#paths-with-a-dynamic-part, #the-registry, api/class-locatorregistry.
- B-12 One registration per path: duplicate error at the locator method (or at `add` with reuse) with both records JSON (`stringifyForLog`); second locator method on one registration; failed method leaves registration as it was (f46b982). `locatorRegistry.ts:314-338`, `locatorRegistrationBuilder.ts:783-882`. Docs: registering-locators#one-registration-per-path, errors#registering.
- B-13 Registration ends at the next registry call (`add`, `getLocator`, `getNestedLocator`, `getLocatorSchema`, `verify`, resolution); ended methods throw first, naming the call; hints for filter args / locator options / queries (890dbd8). `locatorRegistry.ts:153-175`, `locatorRegistrationBuilder.ts:122-159`. Docs: registering-locators#registered-locators-do-not-change, api/class-registrationbuilder, errors#a-registration-that-has-ended, internal/builders, registry-records.
- B-14 Registered locators do not change: copies of options/filters/RegExps (`copyValue`, `readFields` incl. own non-enumerable and prototype values, `copyFields`, `copyFilter`, `normalizeSteps`, `cloneLocatorStrategyDefinition`); clone on every read; seed copies. `utils.ts:184-250,482`. Docs: registering-locators#registered-locators-do-not-change, internal/registry-records#copies-at-every-boundary.
- B-15 First argument rules (`assertStrategyPrimary`, `assertPrimaryValue`, `assertIdValue`): missing / wrong type → missing-value message; empty rejected for locator, frameLocator, getByRole, getById; RegExp only where Playwright takes one. `utils.ts:149-182,445-476`. Docs: registering-locators#the-first-argument, errors#a-first-argument-that-is-missing-or-empty.
- B-16 Steps on a registration: `filter`, `nth`, `describe` (string only, `""` removes); step before a strategy throws; any-frame takes no steps. `locatorRegistrationBuilder.ts:801-862`. Docs: registering-locators#steps-after-the-method, api/class-registrationbuilder#steps.
- B-17 `STRATEGIES` table: ten rows vs Playwright methods and options; `create` per row; `frameLocator(selector)` = `locator(selector)` + steps, `contentFrame()` below; `id` = `[id="…"]` or `internal:attr=[id=/…/flags]`. `utils.ts:302-443`. Docs: internal/strategies-table, registering-locators#the-ten-methods.
- B-18 `getById`: verbatim string with CSS-string escaping (`\`, `"`, LF, CR, FF); RegExp via `escapeRegExpForSelector` (port of Playwright's), every flag passed; empty rejected. `utils.ts:110-146`. Docs: docs/locating-by-id, api/class-registrationbuilder#getbyid.
- B-19 Reuse by path: copy of record (strategy, steps, explicit description), registered at once, view `filter`/`nth`/`describe` only; self-reuse compile error for a single literal, runtime error otherwise (ff6495e); source must be registered first. `locatorRegistry.ts:253-263`. Docs: reusing-locators#reuse-by-path, api/class-locatorregistry#add, errors#reusing.
- B-20 Reuse by seed: `isReusableLocator` shape check, hand-made seed's primary check (method `reuse`), seeded builder: one override with update's argument shapes and JSON Merge Patch (`parseUpdateArguments`, `applyDefinitionPatch`), other strategy throws, second override throws; array reuse message. `locatorRegistry.ts:265-296`, `locatorRegistrationBuilder.ts:763-799`.
